# Бриф на редизайн обвязки сайта

Исполнитель — Claude Code, по этому же документу. Не творческий
поиск, а техзадание: что менять, что не трогать, по каким признакам
проверять результат.

## Диагноз

Сайт сейчас читается как открытый в браузере текстовый документ, а не
как продукт. Причина не в шрифте уроков — в обвязке: плоская шапка
без веса, ссылки вместо кнопок, карточки без объема, портальная
главная не отличается от оглавления файлов. Продукт для чужих
учеников с первого экрана обязан говорить «это сделано», а не
«это распечатка».

## Кого это касается, а что не трогаем

**Меняется:** шапка навигации, кнопки и интерактивные элементы,
карточки (портал, хаб, новости), портальная главная целиком,
разделы `hub/` и `news/` целиком, цветовая и теневая система на
уровне токенов.

**Не меняется:** серифный шрифт и длина абзацев внутри уроков и
статей — сознательное решение, читать как документ там правильно.
Линия хода как артефакт **внутри уроков и статей** остается. Все
жесткие правила подачи из NOTES.md (без буквы "е с точками", без
имен продуктов и ссылок в базе знаний, обезличенный текст) остаются
в силе без исключений.

## Чего не делать — это важнее, чем что делать

Прямой запрет пользователя, проверять на каждом экране:

- **Никакой темной темы.** Сайт светлый везде, без переключателя.
- **Никакого неона, глоу, свечения, градиентных заливок фона.**
- **Никаких клише "ИИ-стартапа"**: фиолетово-синих градиентов,
  стеклянных карточек с блюром, орбов/частиц на фоне, роботов и
  нейросетевых узоров, абстрактных 3D-blob иллюстраций.
- Ничего, что заставляет сайт выглядеть как еще один шаблонный
  лендинг генератора текста. Различимость — часть задачи, не бонус.

## Куда смотреть вместо этого

Направление — чистый продуктовый SaaS (Linear, Stripe, Notion):
светлый фон, много воздуха, крупные заголовки без засечек в
интерфейсных местах, мягкая тень и скругление вместо линий и рамок,
один уверенный акцентный цвет вместо палитры.

Акцентный цвет менять не нужно — нынешний кирпично-терракотовый
(`--accent: #8a2f22`) уже не похож на типовой ИИ-стартаповский
сине-фиолетовый и работает как отличительный признак. Использовать
его увереннее: заливкой в кнопках и активных состояниях, а не только
тонкой полоской слева.

## Техническая спецификация

Конкретные значения токенов. Это не референс для вдохновения, а
величины, которые идут в CSS как есть — с правом скорректировать
на глаз при верстке, но не выдумывать заново.

### Шрифт обвязки

Системный стек недостаточно отличим от «браузер по умолчанию» —
именно он сейчас и создает эффект блокнота там, где нет серифа.
Нужен один самостоятельный гротеск, подключенный файлом, а не через
внешний CDN (сайт статический, self-contained, без сторонних
запросов):

```css
--sans: "Inter", -apple-system, "Segoe UI", "Helvetica Neue", Arial, sans-serif;
```

Один файл переменного начертания (`Inter-Variable.woff2`,
~110 Кб, лицензия SIL Open Font License — можно использовать
свободно), лежит в `assets/fonts/`, подключается `@font-face` с
`font-weight: 100 900`. Без файла подстановка идет на системный
стек — деградация некритичная, но с файлом разница ощутимая сразу.

Начертания: 700 — заголовки и кнопки, 600 — подзаголовки карточек и
названия навигации, 400 — текст кнопок и второстепенные подписи.
Табличные/моноширинные места (`--mono`) не трогать — это часть
языка данных курса, отдельного от языка интерфейса.

### Нейтральная шкала (отдельно от бумажных токенов урока)

Нынешние `--paper`, `--ink`, `--rule` откалиброваны под лист бумаги
и странно ведут себя под тенью и на плашках интерфейса. Для обвязки
— отдельная шкала серого, холоднее и с большим числом ступеней:

```css
--surface:       #ffffff;  /* карточки, поповеры */
--surface-sunk:  #f7f7f8;  /* фон страницы вне листа урока */
--border:        #e6e7e9;
--border-strong: #d5d7da;
--text:          #14161a;
--text-muted:    #62666d;
```

`--accent` и `--accent-bg` остаются как есть — только добавить
`--accent-hover: #6f2419;` (примерно на 15% темнее) для состояния
наведения на залитой кнопке.

### Шкала отступов и скругления

```css
--sp-1: 0.25rem;  --sp-2: 0.5rem;   --sp-3: 0.75rem;
--sp-4: 1rem;     --sp-5: 1.5rem;   --sp-6: 2rem;
--sp-7: 3rem;     --sp-8: 4.5rem;   --sp-9: 6rem;

--radius-sm: 8px;   /* теги, мелкие элементы */
--radius-md: 12px;  /* кнопки, поля */
--radius-lg: 16px;  /* карточки */
```

Нынешние `border-radius: 2px`/`3px` в `.portal-card`, `.agent-card`,
`.resume` и подобных — заменить на `--radius-lg`. Плоские 2-3px
скругления — один из главных источников «казенного» вида.

### Тени (два уровня, не больше)

```css
--shadow-1: 0 1px 2px rgba(20, 22, 26, 0.05), 0 1px 3px rgba(20, 22, 26, 0.08);
--shadow-2: 0 4px 10px rgba(20, 22, 26, 0.06), 0 2px 4px rgba(20, 22, 26, 0.08);
```

`--shadow-1` — состояние покоя карточки, `--shadow-2` — наведение.
Третьего уровня не вводить: две ступени достаточно, три уже читаются
как игра, а не как объем.

### Кнопка — компонент

```css
.btn {
  font-family: var(--sans);
  font-weight: 600;
  font-size: 0.95rem;
  padding: 0.7rem 1.3rem;
  border-radius: var(--radius-md);
  transition: background-color 120ms ease, border-color 120ms ease;
}
.btn-primary   { background: var(--accent); color: #fff; border: none; }
.btn-primary:hover  { background: var(--accent-hover); }
.btn-secondary { background: transparent; color: var(--text); border: 1px solid var(--border-strong); }
.btn-secondary:hover { border-color: var(--accent); color: var(--accent); }
```

Переход по времени короткий (120 мс) и только на цвет — не на
позицию и не на тень. Это тот минимум движения, что разрешен
правилом «движение только в состояниях» (см. lesson.css).

### Карточка — компонент

```css
.card {
  background: var(--surface);
  border: 1px solid var(--border);
  border-radius: var(--radius-lg);
  padding: var(--sp-6);
  box-shadow: var(--shadow-1);
  transition: box-shadow 150ms ease;
}
.card:hover { box-shadow: var(--shadow-2); }
```

Акцентная левая полоска (`border-left: 3px solid var(--accent)`,
нынешний прием в `.portal-card`/`.resume`) — убрать. Вес карточки
дают тень и скругление, а не цветная линия сбоку: с ней карточка
опять читается как документная врезка.

### Шапка навигации

```
высота свернутая:  4rem   (сейчас --navh: 3.25rem — маловато для веса)
высота на скролле:  3.25rem, с --shadow-1 вместо border-bottom
логотип-метка:      20px знак/монограмма + текст, а не голый текст
кнопка справа:      .btn-primary, "Начать обучение", ведет на первый урок
```

### Портальный герой

```
заголовок:      3.25rem / 700 / --sans, до 60% ширины колонки
подзаголовок:   1.25rem / 400 / --text-muted, до 32rem
отступ героя:   --sp-9 сверху и снизу до следующего блока
кнопка:         .btn-primary, размер увеличенный (padding 0.9rem 1.7rem)
```

Три карточки разделов — не в одну строку одинаковой ширины: база
знаний занимает 2 колонки из 3 (или отдельный широкий блок над
двумя младшими), новости и хаб — по одной. Соотношение размеров на
странице должно совпадать с соотношением значимости для нового
ученика.

### Точки перелома

Используются те же, что уже есть в lesson.css (`60rem`, `30rem`) —
новых брейкпоинтов не вводить, встраиваться в существующую сетку.

## Что конкретно строить

### 1. Типографика обвязки

Для интерфейсных элементов (шапка, кнопки, карточки, портальная
главная, хаб, новости) — контрастный современный гротеск, не тот же
сериф, что в теле уроков. Внутри уроков и статей серифный текстовый
блок не трогать вообще. Разница шрифтов между «интерфейсом» и
«документом» должна читаться сразу — это и есть сигнал «продукт».

### 2. Настоящие кнопки

Сейчас переходы — подчеркнутый текст со стрелкой. Ввести компонент
кнопки: скругленный прямоугольник, заливка акцентом для основного
действия, обводка для второстепенного, видимое состояние наведения
(без анимации — просто смена тона) и фокуса. Портальная страница
обязана иметь одну явную кнопку первого действия выше сгиба.

### 3. Карточки с объемом

Портальные карточки, карточки хаба, записи новостей — сейчас плоские
прямоугольники с акцентной линией слева. Дать им вес: мягкая тень
(не резкая, 1-2 уровня подъема), увеличенное скругление углов,
внутренние отступы просторнее. При наведении — едва заметный подъем
тени, без сдвига и поворота.

### 4. Шапка навигации

Сейчас тонкая полоска с текстовыми ссылками — не отличить от меню
файловой системы. Дать шапке собственный вес: логотип-метка вместо
голого текста, кнопка основного действия справа (например, «Начать
обучение»), легкая тень или контрастная граница при прокрутке.

### 5. Портальная главная — как продуктовый лендинг, а не оглавление

Сейчас: заголовок, три одинаковые карточки, подвал. Нужно:

- Полноценный герой-блок: крупный заголовок, короткий подзаголовок
  ценности (не техническое описание, а обещание результата), одна
  явная кнопка действия.
- Полоска доверия/статуса — переосмыслить нынешний счетчик «13 из 45
  готово» как знак того, что материал реальный и растет, а не как
  внутренний прогресс-бар для одного человека.
- Три раздела — не одинаковые карточки-клоны, а с легкой иерархией:
  база знаний — главный вход, крупнее и заметнее; новости и хаб —
  второй план, но не иконки-заглушки, а с собственным характером
  (например, если у хаба уже есть записи — превью реальных карточек
  агентов, не просто текст).

### 6. Разделы `hub/` и `news/`

Сейчас — минимальный текстовый список с пустым состоянием.
Полноценные карточки: у агента в хабе — визуальный акцент на
категории (не только текстовый тег), у новости — визуальная метка
даты, не голая строка шрифтом Courier.

## Признаки, что получилось

Проверять на себе, не только по чек-листу:

1. Открыв портальную страницу первым экраном, без скролла понятно,
   что это за продукт и что нажать дальше.
2. Шапка и кнопки не спутать со стандартной браузерной страницей —
   видно, что их кто-то сделал.
3. При сравнении бок о бок с уроком внутри — разница интерфейс/текст
   читается мгновенно, а не сливается в одно.
4. Ни один экран не хочется описать словом «блокнот» или
   «распечатка».
5. Ни один экран не хочется описать словом «еще один ИИ-стартап» —
   нет градиентов, орбов, стекла, неона.
6. Все проверки `kb/check.py` по-прежнему проходят: правила подачи
   текста в базе знаний редизайн не затрагивает.
