# Отправная точка: вайбкодинг без системного понимания

Заявленный уровень: пробует вайбкодинг, в общих чертах представляет, как работают
нейросети. Python 3.12 установлен, практики в нем нет. Docker не установлен
(проверено). Claude Code используется активно — это единственный агент,
с которым есть живой опыт, пусть и как у пользователя, а не как у разработчика.

Значит: терминология уровня «промпт», «модель», «контекст» скорее всего знакома,
а вот граница между промптом, автоматизацией и агентом — почти наверняка нет.
Начинать надо с различения, а не с определений; код вводить не раньше третьего-четвертого
урока, и через уже знакомый Claude Code, а не с чистого листа.

**Evidence:** прямое заявление пользователя при постановке цели, плюс проверка
окружения (нет Docker, нет API-ключа, Python есть).

**Implications:** практика первых уроков привязывается к Claude Code как к подручному
живому агенту. Локальный Dify недоступен до отдельного урока про Docker —
это блокирует всю платформенную часть гл. 5–6 и должно быть снято заранее,
а не в момент, когда упремся.
